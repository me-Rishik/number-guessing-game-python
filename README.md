# Number Guessing Game

A terminal game where the computer picks a secret number and you try to guess it.

## Features
- Three difficulty levels: Easy (1-50), Medium (1-100), Hard (1-500)
- "Too high / too low" feedback after each guess
- Input validation for wrong entries

## How to run
1. Install Python 3
2. Download or clone this repository
3. Run:

   python main.py
